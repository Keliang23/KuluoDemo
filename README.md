# 推箱子 Demo

使用 Unity 2022.3.51f1 制作的推箱子游戏。包含 5 个教学关卡和 2 个综合关卡，支持冰面、压力板、门与多目标。通关后解锁下一关，自动保存最佳步数。

## 运行

使用 Unity 2022.3.51f1 打开项目，运行 `Assets/Scenes/SokobanDemo.unity`。

主菜单可开始第一关、选择关卡、编辑地图、打开设置或确认退出。设置中可分别调整音乐与音效音量，调至 0 即静音，关闭设置后自动保存。按钮支持悬浮反馈和点击音效。Unity 编辑器中确认退出会停止试玩，打包后会关闭游戏。

## 操作

- WASD / 方向键：移动和推箱子
- Z / Backspace：撤销
- R：重新开始
- Esc：打开菜单

## 地图编辑器

从主菜单进入「编辑地图」，可以新建、命名、编辑和删除关卡，调整地图尺寸，并导入、导出 JSON 文件。支持冰面、压力板和门。

左键绘制，右键擦除，Ctrl + Z 撤销编辑。支持保存草稿和一键试玩；返回编辑时保留原始布局。关卡和进度保存在本机。

箱子进入冰面会滑到普通地板或障碍前；玩家不滑行。玩家或箱子压住压力板时所有门打开，松开后关闭，门上的物体可以离开。新版关卡使用独立进度文件，旧记录与自定义地图保留。
